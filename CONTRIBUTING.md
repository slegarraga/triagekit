# Contributing

Thanks for helping with Triagekit.

## Development

```bash
npm install
npm run dev
```

Before opening a change, run:

```bash
npm run typecheck
npm run lint
```

## Scope

Good contributions for the current phase:

- better issue-form generation rules
- stronger examples for real maintainer workflows
- UI improvements that make copying and testing outputs easier
- documentation and onboarding improvements

## Pull requests

- Keep changes focused.
- Explain the maintainer problem being solved.
- Include screenshots for UI changes.
- Add or update examples when generator behavior changes.
